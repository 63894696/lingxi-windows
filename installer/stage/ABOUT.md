# 灵犀拼音输入法 for Windows — 关于

灵犀拼音输入法（Windows / TSF）由 BabelSpan · Prisir（湃睿思）提供。

产品定位：面向个人与专业场景的本地中文输入工具。核心能力包括拼音/混拼候选、整句解码、简繁输出、本地词库与用户词典管理。

手写走系统 Ink。语音听写为可选组件（SenseVoice Small），在本机完成识别。不做 AI 助手菜单（属独立 PrisirAI 产品）。Windows 端不内置翻译面板。

若需借助 AI Agent 定制输入法，请用菜单「开放 API」：默认关闭，仅 127.0.0.1。

## 使用说明

启用输入法：系统设置 → 时间和语言 → 语言和区域 → 中文 → 语言选项 → 添加键盘 → 选择「灵犀拼音」，并切换为当前输入法。

基本操作：输入拼音后点选候选或按空格上屏；悬浮状态栏可切换中/英、中英标点、简繁，并打开手写、符号、表情、词库、造词与语音听写。

## 隐私政策

灵犀拼音采用严格的隐私保护设计，完全离线无账号运行：

- 键入内容、候选结果与词库数据保存在本机，不向第三方上传输入正文。
- 不提供账号登录，不做行为画像，不出售或交换个人输入数据。
- 用户可通过词库管理自主维护本地词典。
- 可选的语音听写在本机完成识别，不外发音频。
- 开放 API 默认关闭；开启后也仅监听本机 127.0.0.1。

输入法本身不主动发起任何网络请求。

## 开放 API

开放 API 面向「用 AI 帮助用户定制个性化输入法」：本机 Agent / 脚本可通过本地接口查询候选、学习词条、简繁与状态。

默认关闭。状态栏菜单「开放 API」可开关服务并自定义端口（默认 23331），仅监听 127.0.0.1。

配置：`%LOCALAPPDATA%\Prisir\IME\open_api.json`  
端点：`GET /health` · `GET /status` · `POST /rpc`
