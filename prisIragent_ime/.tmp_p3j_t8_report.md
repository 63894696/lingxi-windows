## 8. 关键技术决策与踩坑记录

### D1: 4 个 e2e test 全 #[ignore]
默认 smoke 不跑, 显式 `cargo test -- --ignored` 触发。避免每跑 cargo test 都污染开发机。

### D2: tests/common/mod.rs 公共 helper
- `exe_path()`: 拿 release build 出来的 prisir_tsfsvc.exe 路径
- `spawn_ipc()`: 起 `--ipc` 子进程
- `send_line()`: 喂一行 + 读一行(BufReader 包 ChildStdout)
- `kill_daemon()`: taskkill /F /IM
- `dll_path()`: dll 路径

### D3: ChildStdout 没实现 BufRead
原 spec 用 `stdout.read_line(...)` 编译失败, 改用 `BufReader::new(stdout).read_line(...)`。

### D4: --method 跨进程不持久化
原 spec 假设 `--method` 设置的 active_method 能跨进程持久化(以让 --status 看到), 但实现明确写 "下次启动回归默认(拼音), 进程内立即生效"(`ACTIVE_METHOD: AtomicU8`)。e2e_method_switch 改为:
- `--method pinyin` stdout 自证 (`[method] active: pinyin`)
- `--method wubi` stdout 自证 (`[method] active: wubi`)
- `--method foo` exit ≠ 0 + stderr 含 `unknown method`
- `--status` 默认 pinyin(process-local 默认值)
- 复位 pinyin

### D5: daemon LoadLibrary 锁 dll, set_modified 失败
原方案 `File::set_modified` 在 daemon LoadLibrary 后报 "另一个程序正在使用此文件" (error 32)。验证可行的路子:
- PowerShell `(Get-Item ...).LastWriteTime = ...` **失败**(被锁)
- Rust `std::fs::rename` **失败**(error 5, 拒绝访问)
- Git Bash `mv` **成功**(MSYS 用 _wrename + MoveFileExW, 经 MSYS 内部 share mode 兼容)

e2e_local_lifecycle step (5) 用 `Command::new("mv")` 替换 dll(拷 → 改 tmp mtime → mv 覆盖 dll), 触发 daemon 真 hot reload。

### D6: Drop guard 兜底 panic 路径清理
`CleanupGuard` 在 lifecycle test 失败时仍跑 `--unregister`, 防止 HKCU 残局。

### D7: daemon stdout 实时收
子线程读 stdout/stderr → 共享 buffer,避免 taskkill /F 后 stdout 丢缓冲。
